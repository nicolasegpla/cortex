# Model Selector Inline Specification

## Purpose

This capability has been **removed from the frontend**. The component was unused in production — the n8n chat page does not expose model selection — and is deleted with its tests and styles.

## Requirements

All requirements removed in change `remove-provider-management-frontend` (Reason: n8n chat page does not expose model selection. Migration: None for any — no consumer rendered the component.):

- **Inline Model Selector Badge**
- **Model Selection Popover**
- **Validated-Provider Gating**
- **Keyboard Accessibility**
- **Responsive Layout**
- **Persisted Selection**
